# Inter UI font

`inter-latin-variable.woff2` is the unmodified Latin variable-weight (100–900) WOFF2 served by Google Fonts for Inter. It is self-hosted so the application makes no runtime font requests to third parties.

- Font authors: The Inter Project Authors — https://github.com/rsms/inter
- Source CSS: https://fonts.googleapis.com/css2?family=Inter:wght@100..900&display=swap
- Exact font source: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- License: SIL Open Font License 1.1. The copyright notice and complete license are distributed in `public/licenses/Inter-OFL.txt`, which Vite also copies into the release output.

The Latin subset covers the required English/Spanish UI. Other scripts retain the normal system-font fallback. No package dependency is required.
